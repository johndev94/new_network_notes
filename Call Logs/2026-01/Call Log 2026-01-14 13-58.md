Hi Steve,

I’ve attached a screenshot showing the recommended firmware upgrade path for the Vigor 2860.

When upgrading, please ensure you use the **.all** firmware file and take a **configuration backup regularly** throughout the process.

If there is very little configuration on the device, you could alternatively update directly to the latest firmware using the **.rst** file. Please note that this will reset the device to factory defaults, so any required configuration would need to be re applied manually afterwards.

Following the upgrade path and using the .all file remains the safest approach where configuration needs to be retained.

If you have any questions before proceeding, let me know.
