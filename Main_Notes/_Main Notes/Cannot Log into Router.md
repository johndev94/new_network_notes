Hi Andrew,

  
  
  
  
When you try to access the router's web interface, your browser may default to using HTTPS (e.g., https://192.168.1.1). If that doesn't load properly, try changing it to HTTP instead (e.g., http://192.168.1.1). Sometimes, depending on the router’s settings or certificate issues, one might work while the other doesn’t.  
  
  
  
In regards to the second option of SSH to log in via PuTTY:  
  
  
  
1) Download PuTTY - https://www.putty.org  
  
  
  
2) Open PuTTY and in the IP address field, enter the router’s IP address (e.g., 192.168.1.1).  
  
  
  
3) Set the Connection type to SSH.  
  
  
  
4) Click Open.  
  
  
  
5) A terminal window will appear. When prompted, enter your router's username and password.  
  
  
  
Please let me know how you get on with this.
