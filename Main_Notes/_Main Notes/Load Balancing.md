To enable this, go to WAN > General Setup and ensure the Load Balance Mode is enabled as required.  
  
  
  
For more advanced control over how traffic is distributed across WANs, you can configure policy-based routing. Please refer to the following guide for detailed instructions:  
  
  
  
  
  
https://www.draytek.co.uk/support/guides/kb-policy-routing-guide-v2#load-balancing
