Thank you for contacting DrayTek Technical Support. 

To view all devices in list form and identify which ones have a firmware upgrade available, one approach is to generate a report within ACS.

You can do this by creating a Report Task under Report > Report Tasks, which allows you to generate a device report and have it emailed to you. This report can include firmware version information and clearly show which devices are eligible for an upgrade.

I’ve attached screenshots and step-by-step instructions below to guide you through setting this up.

The following steps and screenshots detail the process:
1. In ACS, go to "Report / Report Tasks" and add a new Report Task (screenshot 1).
2. Select "Comprehensive Report" (screenshot 2).
3. Give the profile a name and select Report Type as "Firmware" and Report Content as "LegacyFirmwareVersion" (screenshot 3).
4. You can select a File Type for the report and the Report Range as selected Network or Devices.
5. Set the Report Recurrence to "Once" for a once off report or else set a schedule (screenshot 4).
6. Select a Recipient User and the email address for them and you can modify further settings below.
7. Save changes and then a report will be sent to the selected recipient(s).

Please don't hesitate get in touch if you need any further support.
