Activate DrayDDNS  

You can activate DrayDDNS from MyVigor Service Status  

1. Click on DrayDDNS and click Activate License Accept terms and conditions and click Activate License. 

2. Wait until is activated and then you can edit the domain name. 

3. Activate DrayDDNS on the router: Applications>>Dynamic DNS, click on a Free Index number and enable, select service Provider DrayDDNS, select WAN interface and Click OK to activate.  

4. If you have not activated on MyVigor when you click Activate DNS and select DrayDDNS this will redirect to MyVigor than follow the steps 1 and 2 above. 


Another way to activate Services is to use Wizards. 


1. Go to Wizards >> Service Activation Wizard page, wait for the router to connect to MyVigor server, then: 

a. Select DT-DDNS 

b. Enter the domain name of your choice. 
 

2. Accept terms and conditions, click next and then click Activate. 

NOTE: If any of these services have has been activated before on the router you will not see these options.  


If this is the case you need to activate from Applications>>DDNS 


3. MyVigor server will reply with the service activation information below. 


4. Vigor router will contact MyVigor server, then retrieve the DrayDDNS license as well as the domain name then create the DDNS profile automatically.  

Go to Applications >> Dynamic DNS Setup page to make sure the router has created the DDNS profile. (Note: If the router did not get the domain after the license activation, it may be due to the router did not communicate with MyVigor server yet. You may reboot the router to trigger the process.)
