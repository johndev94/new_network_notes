API is not enabled on cloud servers.

For self hosted cusotmers the API documentation is packaged with VigorACS 3.4.0 and later.

Linux file path:  /usr/local/vigoracs/VigorACS/bin/acs_util/doc/restful_web_service

The account you enable API access on must be a System Administrator (SysAdmin) user.  
  
Standard user accounts won’t have the necessary permissions to authenticate or perform API actions.
