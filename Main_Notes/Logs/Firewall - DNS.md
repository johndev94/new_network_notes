On the Vigor 2962, you can create FQDN objects by going to Objects Setting > Keyword Object. There, you should see an option to select whether it is a standard keyword or a domain name object, please select domain.

Once created, these FQDN objects can be used in:

- Firewall rules (to allow or block traffic to specific domains)

- Content Security Management (CSM) profiles

- Policy-based routing rules

For reference, I’ve included a guide below which outlines a similar setup using DNS Filter and URL content matching:
