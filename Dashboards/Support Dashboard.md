# Support dashboard

## Calls and tickets
![[Dashboards/Support Work.base]]

New calls start with status **open**. Set status to **waiting** when awaiting a reply, and **done** or **resolved** when finished. Set follow_up to a date to appear in Due follow-ups. Blank follow-up dates have no deadline.

Historical calls are left unchanged. To track an older note, add note_type: call, status: open, and a follow_up date through Properties.

## Daily notes
Use the command **Daily notes: Open today's daily note** to create a dated work journal with planning and learning sections.

The dashboard reflects note properties; completing an individual checkbox does not automatically change the note status. It updates inside Obsidian and does not send notifications.
